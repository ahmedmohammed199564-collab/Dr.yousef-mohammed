# Dr. Youssef Mohamed — Dental Clinic

A modern, responsive one-page website for a dental clinic, built with vanilla
HTML, CSS, and JavaScript. Light/dark mode, full-screen hero, accessible
navigation, FAQ accordion, and an appointment request form.

## Run locally
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy on GitHub Pages
Settings → Pages → Build from branch → `main` / root. The site is static.

## Notes
- Contact details (address, phone, hours, email) are sample data — replace with
  the clinic's real details before going live.
- The WhatsApp links use a placeholder number (`201001234567`) — update it.
- Testimonials are clearly-marked samples to replace with verified reviews.
